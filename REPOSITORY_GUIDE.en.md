# Taking part

[中文](REPOSITORY_GUIDE.md) · [Contribution guide](CONTRIBUTING.en.md)

Ask usage or integration questions in [Discussions](https://github.com/PygmalionSong/enterprise-brain-community/discussions). For a reproducible bug, open an [Issue](https://github.com/PygmalionSong/enterprise-brain-community/issues) with your version, environment, steps and observed result. Please use sample data and remove account details or API keys.

To change code or documentation, submit a Pull Request from your fork. Explain the problem, the resulting behavior and how you verified it. Maintainers review and merge changes; the open-source license does not grant write access to the official repository.

This repository provides a developer source preview. Check the [support scope](PREVIEW_SCOPE.en.md) before starting. For professional exchange, see [Contact](CONTACT.en.md).
