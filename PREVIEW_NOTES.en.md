This is a developer-source preview of a map-free enterprise-agent foundation. Core, migrations, lockfile and the original 69 SDK test files retain accepted bytes; the maintainer's earlier fixed SDK matrix passed 641 checks. That historical result is not a new641 run for these document changes, customer/vendor evidence or full-server acceptance.

Verify the complete inventory, locked dependencies, types/build and first-task checks. Source reproduction runs four SDK shards plus the three first-task checks once; the final gate requires both. After publication, inspect the actual commit's Actions result rather than a generic badge. A static workflow is not a completed CI result.

The first task uses owned constructed processes, roles and source ledgers. It actually commits before losing a response; a fresh process reopens the original database and looks up the original action. This is not HTTP login/SSO, a real enterprise or model-quality evaluation. Users explicitly create a minimal local report; it is not uploaded automatically. Keep output databases, keys, checkpoints and raw logs private.

This source excludes the complete cockpit/maps/signed enterprise bundle and installed dependencies. Windows x64/Node24.19.0 is the declared route; complete clean-customer-host operations, Linux, live-model quality and universal vendor compatibility remain unverified. The full-product direction is separate from this source-distribution scope.

REPOSITORY_MANIFEST.json checks the complete distribution; SOURCE_MANIFEST.json checks current bytes within the original SDK scope. Hashes establish consistency, not publisher signatures or production certification. Retain LICENSE/NOTICE and third-party terms; see [asset scope](ASSET_SCOPE.en.md) and the [support matrix](PREVIEW_SCOPE.en.md).


For this document/evidence curation, the original388-file base was checked in isolation for inventory, types, build and one actual first-task run. Verify any future public commit against its actual Actions; do not relabel the base inventory result as new-commit CI.
