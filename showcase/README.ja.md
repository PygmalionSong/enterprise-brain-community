# 業務体験の説明

[English](README.en.md) · [中文](README.zh.md) · [日本語](README.ja.md)

現在のデスクトップブラウザーで[対話型ワークスペース](index.html)を開くか、承認済みの静的サーバーで本ディレクトリーを配信してください。画面は日本語・英語・中国語に対応します。アカウント、依存関係の導入、モデルキー、企業接続先は不要です。検証用ブラウザーはfile方式を許可しなかったため、実際の確認はローカルHTTPで実施しました。WeChatの添付ファイルはHTTPSサイトではなく、公開ホスティングには別途承認が必要です。

Processesから15の業務領域を確認できます。Overviewでは国内5地域、省・都市、海外6市場、期間、指標を選択します。ガイドを開くと、全体像を保ったまま案件を順に体験できます。

案件は2026年10月12–18日の華南・即時消費です。追加需要160万ケースに対し、自社生産80、移送60、委託生産20を比較します。現金5220万元と増分費用1040万元は別指標です。現金上限4500万元、品質の前提未達、内部資源だけでの不足は承認を妨げます。明示的な承認で計画を固定し、4件の実行証跡、財務支払、10月18日の結果を個別に確認します。入庫160＝販売148＋在庫12万ケースであり、入庫は売上ではありません。

店舗画面では冷蔵商品の在庫充足、通行密度、滞在、時間帯、棚、試験条件を確認できます。ヒートマップは各指標内で固定した相対密度指数です。実人数や実カメラの観測ではありません。

地図を使わない独自設計の参照用業務環境です。データと洞察は構成例で、地域カードは業務上の関係を示します。グループ決算は2026年9月まで、10–12月は予測で、案件と店舗には別の日付があります。企業・地域・財務・顧客・店舗の数値はサントリーの開示値や顧客実績ではありません。第三者のロゴ、地理形状、顧客画像、実センサーは含みません。大企業の規模感は設計上の参考であり、実績や開示データセットの再現ではありません。

操作はブラウザー内の参照案件だけを変更します。実際の承認、支払、在庫移動、顧客連絡、モデル推論は発生しません。案件と言語はenterprise-brain.public-showcase.v1に保存され、参照環境のリセットで初期化できます。自動テレメトリー、送信、端末間同期はなく、SDKデータベースにも接続しません。

永続的な実行は[ソースのホーム](https://github.com/PygmalionSong/enterprise-brain-community/blob/main/README.ja.md)から導入・ビルドし、[最初のタスク](https://github.com/PygmalionSong/enterprise-brain-community/blob/main/FIRST_TASK.ja.md)で確認してください。独立プロセス、承認、応答喪失後の再開、元の操作の照会を検証します。画面の案件とは別の証拠です。自動システム発見、実SAP/Dynamics互換性、モデル品質、本番認定、組織全体の創発知能の証明ではありません。
