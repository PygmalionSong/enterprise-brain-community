# v0.1.0-preview.2 — bounded first connection

[中文](RELEASE_NOTES.md) · [Start](README.md) · [First connection](FIRST_CONNECTION.en.md)

This preview adds persistent authorized endpoints, protocol/metadata observations, IT field review and separate business read approval. An application explicitly installs the SDK business-read tool; the default HTTP catalog does not expose it. Original read receipts and restored-authority fencing support bounded recovery.

The existing operating reference uses constructed data and deterministic policies. Its supply path separates approval, assignment acceptance and verified receiving. The independent browser showcase is a separate local-state example; it does not establish actual payment, sales, customer ROI or model reasoning quality.

Supported transport is bounded to authorized literal private IPv4 or loopback targets. DNS, IPv6, subnet discovery, credential-backed adapters and complete MCP HTTP are not implemented. OData metadata is not a workflow definition. This source preview is not the complete signed one-step runtime installer or production qualification.

Apache-2.0 remains unchanged. [Source attribution](ATTRIBUTION.en.md) explains notices without adding restrictions. Business plans, company-specific process designs, credentials and customer material are excluded. See [scope](PREVIEW_SCOPE.en.md) and [validation notes](PREVIEW_NOTES.en.md) for tested boundaries.
