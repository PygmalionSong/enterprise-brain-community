# Preview scope

[中文](PREVIEW_SCOPE.md) · [Home](README.md)

This developer source preview has three entries. They share contracts and case context but have distinct evidence and state.

| Entry | Included | What it does not establish |
|---|---|---|
| Browser showcase | Three-language15-domain business blueprint, constructed charts/insights, local case interaction | Backend execution, real enterprise/model/sensor data; its browser state is separate |
| Local operating reference | Persistent backend, separate constructed HTTP/SQL sources, approval, supply execution and receipt verification | Payment/sales outcomes, every domain executable, production deployment |
| Foundation SDK | Process registry/readers, bounded graphs, installed tool contracts, identity, policies, model configuration/budgets and operations modules | Universal discovery/connectors, complete enterprise semantics, live-model quality |

Start with the [browser case](showcase/index.html), [local reference](RUN_OPERATING_CASE.en.md), [controlled task](FIRST_TASK.en.md) or [small adapter](EXTEND_A_SOURCE.en.md).

| Boundary | Current scope |
|---|---|
| Environment | Windows x64 / Ubuntu24.04 x64, Node24.19.0, pnpm11.25.0. Locked35-package dependency set; install/build required. Ubuntu24.04 x64 source/native scope is described in LINUX_RUNTIME.en.md; independent customer-host qualification remains unverified. |
| Persistence | PGlite and native PostgreSQL 17.11 have distinct contracts. Backup/restore/upgrade source modules are included within their documented scope, not HA or turnkey DBA provisioning. |

| Execution | Versioned definitions/relationships, frozen acyclic graphs, separate approval, action identities, submit/lookup and receipt checks. No arbitrary loops/nesting/dynamic dataflow or universal exactly-once. |
| Models | Explicit installation and structured contracts, authorized context and budgets; the reference uses deterministic policies. No measured live-model insight quality. |
| Enterprise host | Identity/access UI and documented local/enterprise host modules. No demonstrated SSO/MFA, horizontal scale or clean customer production operation. |
| Distribution | Source, tests, media, lockfile, licenses and inventory. No signed complete installer, Node binary, installed dependencies, runtime databases or geographic shapes. |

One-step private deployment, broader operator-confirmed IT discovery and organizational decision support remain product goals. Existing ERP/SRM/WMS/CRM systems retain their ledgers. This scope is not a paid-feature boundary. package.json private=true prevents unintended npm publication. Check actual Tags/Releases/Actions for public availability and exact CI; documentation is not evidence of publication. See [architecture](ARCHITECTURE_OVERVIEW.en.md), [validation](PREVIEW_NOTES.en.md) and [asset/data scope](ASSET_SCOPE.en.md).


## First-connection scope

Protocol/metadata identification targets explicitly authorized literal private IPv4 or loopback endpoints. DNS, IPv6, subnet discovery, production credentials and complete MCP HTTP are absent. IT source validation and business read approval are separate. The read factory requires explicit installation and is not enabled in the default HTTP catalog. See [first connection](FIRST_CONNECTION.en.md) for source scope, grants, receipts and restoration boundaries. Source, signed runtimes and vendor production qualification have separate acceptance.
