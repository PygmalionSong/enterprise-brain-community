# Questions and contributions

Ask usage and integration questions in [Discussions](https://github.com/PygmalionSong/enterprise-brain-community/discussions). Report reproducible bugs in [Issues](https://github.com/PygmalionSong/enterprise-brain-community/issues) with the version, environment and a redacted reproduction. Propose code and documentation changes through Pull Requests.

For vulnerabilities, read the [security policy](SECURITY.en.md) and use the private reporting option actually available on the repository Security page. Do not post exploit details or credentials publicly. Review installation reports before sharing; exclude databases, customer records and unredacted logs.
