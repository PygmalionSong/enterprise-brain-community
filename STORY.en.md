# What happens when an agent can follow a whole business process?

[中文](STORY.md) · [日本語](STORY.ja.md)

An order can involve sales, inventory, production, purchasing and finance. Each system holds part of the picture; each team understands its own work. What might an agent notice when those parts are considered together? We thought that was an interesting question to build around.

Enterprise Brain is a self-hosted foundation for enterprise AI agents. We want teams to run agents in their own environment, read authorized process context, compare alternatives, carry out approved work and check what actually happened.

We started with a concrete question: a region needs more stock. A transfer, more production or co-packing might help, with different consequences for delivery, quality, inventory and cash. Could an agent bring those constraints together, explain a recommendation and retain the source receipt after execution? That seemed worth trying.

A beverage case gives the project somewhere concrete to run and test. We plan to explore other industries and learn which parts carry over, and which decisions need human judgment. Models can change; process context, authority and execution evidence still need a dependable home.

We are sharing the work as we go. Explore the case, run the code, connect an owned test source or tell us where the design falls short. We would like to learn whether it helps with something you are building, and what is missing.

See [validation notes](PREVIEW_NOTES.en.md) for current reproducible scope. Complete enterprise-wide discovery and universal connections remain future work.
