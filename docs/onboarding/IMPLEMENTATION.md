# 首次接入：当前实现与边界

[English](IMPLEMENTATION.en.md)

IT操作人先授权准确端点范围，产品再读取并记录协议证据。操作人核对系统归属和用途后，固定适配器执行元数据读取测试。OData实体并不等于业务工作流。

当前传输只支持明确的私网IPv4或127.0.0.1端点，禁止重定向和代理；HTTPS严格核验证书。没有DNS、IPv6、网段扫描、凭证存储或完整MCP HTTP客户端。多个URL不能自动当成同一个系统。发现候选不会自动取得读取或流程执行权。

IT可以从当前来源验证实体、字段、用途和行数界限。业务账号另行批准有期限的读取授权；IT核对不代替业务批准。政策、授权和来源验证回执持久化。执行前、结果提交和后续披露均重验当前权限；撤权后的缓存数据不会继续显示。权限撤销不能撤回已发送的字节。

`businessReadGraphTool`提供同数据库事务守卫的显式SDK安装工厂。默认HTTP工具目录尚未注册这个工具。不能把工厂测试或授权页面等同于默认宿主已开放业务读取。企业工作流仍需导入并核对受支持的定义，确认后的计划另获业务执行批准。

读取动作保留原引用和回执。回应丢失或进程中断后先查原引用，不自动再次GET；无法确定的结果保留未知。恢复会撤销新接入授权、保留已完成证据，将已发出但未确认的工作标记为未知。PGlite恢复目标初始停放，需重新登录和确认授权。

Windows与Ubuntu的实现、源码测试、真实数据库合同、签名整包和独立宿主验收分别记录。任何一项通过都不代表所有厂商系统、生产认证、高可用或无限容量已获验证。
