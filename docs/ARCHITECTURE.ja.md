# 業務とシステム構成

業務図は関連する責務、技術図は基盤・モデル・既存システムの関係、判断の流れは供給事例での計画比較と確認を示します。実行できる範囲は[プレビューの範囲（英語）](../PREVIEW_SCOPE.en.md)で確認できます。

## 部門をまたぐ課題を一緒に考える

供給不足には需要・在庫・生産能力・納期・資金が関わります。事例で業務間の関係を確認できます。各システムは引き続き業務記録を管理します。

[![部門をまたぐ課題を一緒に考える](diagrams/business.ja.png)](diagrams/business.ja.svg)

## チームが再利用できる基盤

基盤が業務プロセスを保存し、操作権限と承認を確認して実行結果を記録します。接続先、製品、単位、承認ルールは企業ごとに設定します。モデルの提案を実行する前に、プログラムが権限を確認します。

[![チームが再利用できる基盤](diagrams/systems.ja.png)](diagrams/systems.ja.svg)

## 計画から実行結果まで追う

供給事例では、生産能力・資金・品質の条件をそろえて自社生産・移送・委託生産を比較します。承認・システム受付・入荷は別に確認し、支払と販売にはそれぞれの証憑が必要です。

[![計画から実行結果まで追う](diagrams/decision.ja.png)](diagrams/decision.ja.svg)
