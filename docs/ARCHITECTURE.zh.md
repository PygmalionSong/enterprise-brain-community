# 业务与技术架构

下面三张图分别说明：供货缺口涉及哪些部门，Agent怎样连接现有系统，以及一个方案从提出到执行需要经过哪些步骤。具体可运行范围见[版本说明](../PREVIEW_SCOPE.md)。

## 跨部门的问题，放在一起判断

供货缺口要同时看销售需求、库存、产能、交期和现金。案例展示这些业务怎样关联；各系统仍负责自己的记录。

[![跨部门的问题，放在一起判断](diagrams/business.zh.png)](diagrams/business.zh.svg)

## 企业团队可以复用哪些基础设施

底座保存业务流程、检查操作权限，并记录方案的批准和执行结果。接入一家企业时，还需要配置系统接口、商品和计量单位，以及这家企业的审批规则。模型负责提出建议，执行前仍由程序检查权限。

[![企业团队可以复用哪些基础设施](diagrams/systems.zh.png)](diagrams/systems.zh.svg)

## 方案怎样走到结果

保供案例在同一组产能、现金和质量条件下比较自产、调拨与代工。批准、系统受理和到货分别核对；付款和销售需要各自的业务凭据。

[![方案怎样走到结果](diagrams/decision.zh.png)](diagrams/decision.zh.svg)
